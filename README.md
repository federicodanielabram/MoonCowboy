# Moon Cowboy

Proyecto personal en **Unreal Engine 5.8**: un juego en tercera persona ambientado en la Luna — un personaje mitad cowboy, mitad astronauta, cruza en moto el camino entre dos colonias lunares, con una mecánica de oxígeno que obliga a planear desvíos por el recorrido.

## Qué hay en este repo

Blockout jugable del mapa (22×22km), blueprints propios, UI (brújula, HUD de oxígeno) e input. Es un proyecto en etapa de diseño de nivel, no un juego terminado.

## Lo que falta para correrlo completo

Este repo **no incluye** los assets comprados en Unreal Marketplace/Fab que usa el proyecto (sus licencias no permiten redistribuir los archivos fuente):

- Modelo y blueprint de la moto (Chaos Vehicles)
- Pack de animaciones de interacción con la moto
- Pack de animaciones libres (FreeAnimationsPack2)

Para correr el proyecto completo hace falta volver a instalar esos packs desde Fab en `Content/Bike/`, `Content/MotoInteractionAnims/` y `Content/FreeAnimationsPack2/`.

## Stack

Unreal Engine 5.8, Blueprints, Chaos Vehicles Plugin, MetaHuman.
